# Code 工作台的表面和能力入口

- Code 首页上方保留真实字标、输入区和用量摘要，下方为会话看板。空闲默认九条，搜索和归档仍看全部匹配项。侧栏可就地搜索所有工作区，切换沿用原项目、草稿、会话机制。
- 按钮语义色取已有 V2 调色板，保留主题与壁纸磨砂。Chat/Code 仍用原应用主导航；ButtonV2 图鉴留在 UI Storybook。
- 近期图片复用已加载消息中的成功文件成果。不为首页拉取历史消息；只给有小体积元数据的图预取，其他图片按需读取。图片不在缓存时不展示样例卡。
- Skill Deck 使用当前目录的斜杠命令目录。点击插入既有命令，不自动发送，不覆盖草稿；“已装载”来自当前会话的成功 `skill` 工具结果，而非浏览或插入。最近选择和收藏留在 GUI 偏好。
- 模型看到的输入、工具协议和固定缓存前缀无新增：用户主动发送与手输同一条命令走同一路径，新增选择记录不注入上下文。Chat、TUI、模型工具和权限流程未改。
